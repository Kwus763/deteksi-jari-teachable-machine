# Deteksi Gestur Jari (Teachable Machine)
Proyek sederhana menggunakan TensorFlow.js dan Teachable Machine untuk mendeteksi gestur tangan (3 jari dan 5 jari) melalui webcam.

## Cara Menjalankan:
1. Clone atau download repository ini.
2. Pastikan struktur folder `my_model/` sudah lengkap (`model.json`, `metadata.json`, `weights.bin`).
3. Buka file `index.html` di browser (atau gunakan extension Live Server di VS Code).
